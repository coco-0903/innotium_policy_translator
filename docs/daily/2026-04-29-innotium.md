**핵심 변경 내용**:

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 출력 형식 | 필드명 나열 + 간략 설명 | `[설정] > App Setting > [제품] > 섹션` 경로 헤더 |

| 값 해석 | true/false/숫자 그대로 | 활성화/비활성화/의미어 자동 변환 |
| 위험 설정 | 보안 영향도 이모지만 | ⚠️ 표시 + 위험 내용 명시 |
| 빈 값 처리 | 누락 | "등록된 항목 없음" 명시 |
| 예시 출력 | 없음 | 시큐어존 에이전트 정책 완성 예시 포함 |

**필드→UI명칭 매핑 추가 (주요 항목)**:
- `isClipboardRestrict` → 클립보드 공유제한
- `usbControlAuth` → 휴대용 디바이스 권한 (0=미사용/1=읽기전용/2=완전차단)
- `isTakeoutDriveBlock` → 반출드라이브 차단
- `behaviorDetectLevelType` → 행위기반 탐지 민감도 (LOW 0.3초/8회, MED 0.5초/5회, HIGH 0.8초/3회)
- `isRollbackUse` → 롤백(자동복구) 사용
- `isWatchFile` → 파일 감시기능
- `isRegistEcmDrive` → ECM 드라이브 연동 등록
- `isAutoLock` → AutoLock 자동 잠금
- 총 50개 이상 매핑 (6개 제품 전체)

## 현재 프로젝트 전체 상태 (인수인계용)

### 프로젝트 개요

이노티움(Innotium) 보안 플랫폼 v11 (6개 제품)의 정책 JSON을 분석·번역·진단·시뮬레이션하는 Flask 기반 AI 웹 앱.
신입 엔지니어 교육 + 실무 담당자 정책 분석 용도.

### 아키텍처

```
[사용자 브라우저]
      │
      ▼
[Nginx :40010] ──→ [Gunicorn :5000] ──→ [Flask app.py]
                                               │
                          ┌────────────────────┼────────────────────┐
                          ▼                    ▼                    ▼
                 [Claude Haiku]        [Claude Sonnet]        [MariaDB :43306]
                 (챗봇·로그·ZIP)       (번역·진단·분석)        (READ ONLY)
                          │
                          ▼
                 [ChromaDB RAG]
                 (417청크 / 7개 PDF)
```

### 파일 구조

```
app.py          — Flask 라우트 + AI 프롬프트 + 도메인 지식 (POLICY_KNOWLEDGE)

rag.py          — ChromaDB 인덱싱/검색 (RAG 엔진)
db.py           — MariaDB 연결 + 쿼리 (12개 정책 테이블 READ ONLY)
static/
  index.html    — 전체 UI (사이드바 + 챗봇 + 분석 도구 + DB 조회 + 로그 분석)
  script.js     — 프론트엔드 로직
  style.css     — 스타일
corrections.json — 챗봇 오답 수정 내역 (자동 생성됨)
chroma_db/      — RAG 벡터 DB (서버에 존재, git 미추적)
docs/manuals/   — 제품 PDF 기능분析서 (서버에 존재, git 미추적)
```

| # | 현상 | 원인 | 해결책 |
|---|------|------|--------|
| 1 | `credit balance too low` 오류 | API 키를 크레딧 충전 전에 발급 | 기존 키 삭제 → 충전 후 새 키 발급 → `.env` 교체 |
| 2 | `Unexpected token '<'` JSON 파싱 오류 | Gunicorn/Nginx 타임아웃 초과 → HTML 에러 페이지 반환 | Gunicorn `--timeout 300`, Nginx `proxy_read_timeout 300s` |
| 3 | Rate Limit 429 (토큰 초과) | POLICY_KNOWLEDGE ~15K 토큰 × Sonnet = Tier 1 한도 초과 | 챗봇/로그 → Haiku로 분리 (50K/분 한도) |
| 4 | `git pull` 충돌 | 서버에 직접 수정된 파일 + 미추적 `rag.py` | `git stash && mv rag.py rag.py.bak && git pull` |
| 5 | 챗봇이 빈 배열을 "기능 없음"으로 오해 | `[]` 반환 시 AI가 기능 미존재로 판단 | CHAT_SYSTEM_PROMPT에 "빈 배열 = 항목 미등록, 기능은 존재" 명시 |
| 6 | ZIP 분析 결과 안 뜸 (element ID 불일치) | `runZipAnalyze()`에서 존재하지 않는 ID 참조 | `resultState`, `loadingState`, `emptyState` ID로 수정 |
| 7 | ZIP 분析 500 오류 | Sonnet 속도 느려 Gunicorn 타임아웃 초과 | ZIP 분析 엔드포인트를 Haiku로 전환 |
