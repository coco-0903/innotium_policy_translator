## 트러블슈팅

### 🔴 502 Bad Gateway (배포 직후)

**증상**: 서비스 재시작 후 모든 API 502 응답

**원인**: `CHAT_TOOLS` 정의 시 `{{` / `}}` 이중괄호 사용
```python
# 잘못된 코드 (f-string 밖에서 이중괄호 → dict 리터럴 파괴)
"input_schema": {{"type": "string"}}

# 올바른 코드
"input_schema": {"type": "string"}
```
Python이 `{{"type": "string"}}` 을 `{"type": "string"}` 딕셔너리가 아닌
frozenset/hashable 오류로 해석 → `TypeError: unhashable type: 'dict'`
→ Flask 앱 임포트 실패 → Gunicorn worker 크래시 → 502

**해결**: `CHAT_TOOLS` + `_execute_tool()` 내 모든 `{{` → `{`, `}}` → `}` 전환

### 🔴 분석 이력 시간 +9시간 오차 (KST 오프셋 누락)

**증상**: 이력 카드에 표시되는 시간이 실제보다 9시간 느림
(예: 오후 5:11 → 다음날 오전 2:11로 표시)

**원인**: PyMySQL이 DATETIME 컬럼을 Python `datetime` 객체로 반환
→ Flask `jsonify`가 UTC 기준 ISO 문자열로 직렬화 (`"2026-04-02T08:11:00"`)
→ JavaScript `new Date("2026-04-02T08:11:00")`은 로컬 타임존 없으면 UTC로 해석
→ KST(+9) 환경에서 +9시간 오차 발생

**해결**: 두 레이어에서 동시 처리

```python
# db.py — SQL에서 문자열로 포맷 (timezone 오염 방지)
cur.execute(
    "SELECT id, analysis_type, product, input_summary, "
    "DATE_FORMAT(created_at, '%%Y-%%m-%%d %%H:%%i:%%s') AS created_at "
    "FROM pa_history ORDER BY created_at DESC LIMIT %s",
    (limit,)
)
```

```javascript
// script.js — JS에서 +09:00 명시적으로 붙여 파싱
function parseKST(dtStr) {
    if (!dtStr) return null;
    const s = String(dtStr).trim().replace(' ', 'T');
    const withTz = (s.includes('+') || s.endsWith('Z')) ? s : s + '+09:00';
    const d = new Date(withTz);
    return isNaN(d.getTime()) ? null : d;
}
function fmtDatetime(dtStr) {
    const d = parseKST(dtStr);
    if (d) return d.toLocaleString('ko-KR');
    return dtStr ? String(dtStr).substring(0, 19).replace('T', ' ') : '';
}
```
